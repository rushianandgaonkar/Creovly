# Creovly keyword map (US, Nov 2026)

Source: OpenSEO keyword research, US/English. Seeds: "youtube thumbnail",
"youtube money calculator", "youtube shorts safe zone", "youtube title".
Columns: monthly searches (US) · KD = keyword difficulty, 0–100 (lower is easier).
Some close variants share one volume figure, so don't add them together.

## 1. Pages that already exist: target these keywords

Use the **primary keyword** in the page `<title>`, H1, meta description, the
first 100 words and one H2. Work the secondary keywords into H2s, FAQs and
body copy. Only describe what the tool actually does.

## 3. Skip for now

- **youtube thumbnail downloader / grabber / extractor** (14,800, KD 36): Creovly doesn't have this tool.
- **youtube thumbnail maker / generator** (4,400, KD 44+): high difficulty, and Creovly isn't a design editor.
- Brand or navigational searches ("youtube login", "is youtube down"): not relevant.
